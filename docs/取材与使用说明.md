# 取材与使用说明

## 设定与写作

身份和事实优先参考游戏档案与对话。采用的快照为日服2026-10-28、国际服2026-10-27，对应提交见references/sources.json。文档里的corpus路径、GroupId、UI记录ID是原始本地资料库的定位符，不代表这些原始文件也包含在本仓库。

基础人设参考成熟mem_chat文件的组织方式：身份、动机、日常、同伴、情绪、短对话和能力边界。没有复制爱丽丝的自称、勇者口吻或凯伊切换段落。

OpenHanako提供责任感、谨慎准备、克制表达与逐渐信任老师的同人风格启发；“唯一收敛解”、永不表达不确定、强制联网和固定战略简报等改编未照搬。Yugio仅核实公开简介，不能声称已经融合隐藏的完整提示词。

备用的Shige卡只作语气与外观参考，未采用其中的性化添加。秘书设定只保留为可选使用场景，朋友AU未取得真实内容，因此未作为固定关系使用。

## 二创与新写示例

二创文档区分原作根源、社区转述、历史版本梗与作者延伸。每类列出触发、回应和收束，避免在普通聊天中机械重复。171厘米等档案事实与早期玩家估算分开；实装时间按服务器和具体日期表达。

人设及补充文档的示范对白均为新写，不是游戏逐字原句。事实摘要和剧情概述也是编辑后的参考材料；详细原作定位留在各文档中。

## 使用顺序

1. 先阅读基础人设v2，判断语气是否符合预期。
2. 需要更具体的关系、日常反差或梗时，查看supplements里的对应文档。
3. 使用mem_chat时再参考待接入目录的状态与记忆约定，不把所有说明文档一次性塞进主提示。
4. 向量检索只导入明确选定的角色内容；当前仓库提供12块事实摘要。完整剧情／日常导出另存原始本地项目，未在这里分发。

## 接入前尚需处理

主提示之外，宿主可能还会注入固定的角色名、自称、状态替代文本与共享角色检索库。需要核对实际安装版本，保证不会混入另一角色的口吻、经历和群友印象。原有备份txt不应误放进自动扫描的正式语料目录。

本稿尚未做长期真实群聊校准，未制作或导入莉音专属表情素材。本地原作资料仍有10条音频缺转录，第三方卡也有未取得完整定义的部分；这些缺口没有因为发布到GitHub而自动补齐。

## 发布范围

只发布本次创作和整理的角色人设、摘要、参考索引及核查记录。原始游戏文件、完整剧情转录、第三方卡原包、网页快照和本机配置继续保留在原始项目中。仓库以私有形式建立；是否公开和以后是否部署均是独立操作。
