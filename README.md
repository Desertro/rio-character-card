## 这版的表现方向

用“我”自称，平静、直接、有自己的判断。她重视合理性与准备，也能承认未知、修正错误、接受同伴的帮助。日常有独特审美与生活盲点，关心常体现在具体安排和不太坦率的邀请里。

梗按情景使用：大姐头／Big Sister、下水道／水沟水、183厘米旧估算、等实装旧梗、认真过头的生活反差、前卫君审美、女仆机器人，以及会长也要收拾便当盒。旧梗不会改写档案与实装事实；所有新写示例均标明为示范。

## 用于 mem_chat

[待接入目录](persona/mem_chat_ready/README.md) 提供同一份人设正文、10个状态键规则，以及12块作者整理的角色事实摘要。

此仓库是角色资料交付，未替换任何运行中的机器人。实际接入前需要处理宿主内固定的角色名、自称、状态兜底与角色语料／人物记忆的隔离。正文不是可直接导入的SillyTavern PNG／JSON卡。
